Brainstormen met een agent

Veertien design thinking-technieken die je in je eentje kunt doen, met een agent als sparringpartner. Per techniek: wanneer je hem gebruikt, wat hij oplevert, hoe lang hij duurt en welk deel je zelf doet.

Zo werk je met een agent

  1. Geef context meeJe probleem, je gebruikers, je eigen eerste ideeën. Hoe meer de agent weet, hoe minder hij verzint.
  2. Laat de agent verbredenVragen, varianten, veel ideeën, ook gekke. Daar is een agent sterk in.
  3. Kies en controleer zelfDe agent kent je gebruikers, je klant en je budget niet. Kiezen is jouw werk.

Drie gewoontes: eerst zelf, dan de agent. Eindig je prompt met "Kies nog niets". En zeg "weet ik niet" als je het niet weet; dat wordt een open vraag voor de business.
