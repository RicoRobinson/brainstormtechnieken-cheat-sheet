# Brainstormen met een agent

Cheat sheet met tweeëntwintig design thinking-technieken die je in je eentje kunt doen, met een AI-agent als sparringpartner. Per techniek staat erbij wanneer je hem gebruikt, wat hij oplevert, hoe lang hij duurt, welk deel je zelf doet, en een startprompt om te kopiëren.

Gemaakt voor de workshop AI for Design op de Mendix-meetup van 25 november 2026. De pagina is tweetalig (NL/EN).

**Bekijk hem hier:** https://ricorobinson.github.io/brainstormtechnieken-cheat-sheet/
